# Reusable Design Language Prompt

Use this prompt when you want another website to feel visually consistent with this portfolio.

## Copy-Paste Prompt

Design a compact editorial portfolio website with a restrained, high-precision interface. The visual language should feel like a minimal digital archive, a creative developer portfolio, and a quiet systems UI at the same time.

Use a dark-first monochrome palette: pure black background, white foreground text, soft muted white text for secondary content, and very thin translucent borders. Include an optional light theme using an off-white background and near-black text. Keep accent color extremely limited, using a cool electric blue only for subtle glow or tiny emphasis, not as a dominant color.

Typography should do most of the visual work. Use a sharp modern display sans such as Clash Display for headings, navigation, labels, buttons, and body text. Keep font weights mostly regular. Use uppercase headings and labels, small technical metadata, tabular-looking numbers, and generous but controlled line height. Avoid decorative type pairings.

The layout should be dense, gridded, and architectural. Build pages from rectangular sections divided by 1px borders. Use fixed-feeling frames, index numbers, section strips, metadata rows, and table-like content blocks. Avoid rounded cards, soft shadows, floating panels, blobs, gradients, and ornamental decoration. The design should feel deliberate, calm, and structured rather than flashy.

Header: create a fixed top navigation bar with a translucent blurred background, centered navigation links, a small uppercase brand on the left, and a compact theme toggle on the right. Navigation items should be uppercase, tiny, letter-spaced, and separated by thin vertical borders. Active states should be subtle: brighter text, a faint background, and a 1px bottom rule.

Hero: avoid oversized marketing composition. Use a bordered editorial hero module with a thin top strip showing page index and location/status metadata. Inside, use a two-column grid: the left column contains a compact uppercase brand mark, a short large-but-restrained statement, and text-link actions; the right column contains a small animated/system detail, then indexed rows for focus, availability, location, and contact.

Content sections should use section headers with tiny uppercase labels on the left and counts/status on the right. Body sections should be divided into 2- or 3-column grids with border separators. Use numbered content blocks, compact profile cards, metadata manifests, skill tags, project details, and gallery grids.

Images should be real project visuals inside strict bordered aspect-ratio frames. Use object-fit cover. On hover, add a subtle scan-line overlay or faint white wash, not a dramatic zoom. Image labels may appear as tiny uppercase tags on hover.

Buttons and links should mostly be text links with underline/bottom-border treatments. Use arrows sparingly for navigation or external links. Avoid filled CTA buttons unless absolutely necessary. Interactions should be quiet: slight opacity changes, 1px border color changes, tiny horizontal shifts, and short smooth transitions.

Spacing should be compact but breathable. Use responsive padding with clamp values, a centered max content width around 80rem, and section gaps around 1.5rem. On mobile, stack grids into one column while preserving borders, labels, index numbers, and the editorial structure.

Overall keywords: compact, editorial, monochrome, indexed, bordered, archival, deliberate, technical, minimal, grid-based, calm, precise, developer portfolio, quiet interaction design.

## Style Checklist

- Background: black first, optional off-white light mode.
- Text: white, dim white, muted white; avoid colorful body text.
- Accent: cool blue only as a rare detail.
- Fonts: Clash Display or similar geometric display sans.
- Corners: square or nearly square.
- Borders: 1px translucent rules everywhere.
- Layout: centered max-width frame, gridded content, section strips.
- Labels: tiny uppercase metadata with letter spacing.
- Structure: numbered rows, manifests, project specs, skill tags.
- Images: bordered, fixed aspect ratio, real visuals, subtle scan hover.
- Motion: minimal, smooth, functional.
- Avoid: gradients, shadows, rounded cards, decorative blobs, oversized landing-page hero style.
